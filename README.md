## 安裝說明

1. 下載並執行 `AwayTerminal-Setup-1.0.0.exe`。
2. 若跳出「Windows 已保護你的電腦」→ 點 **其他資訊 → 仍要執行**。
3. UAC 出現按 **是**（安裝需系統管理員權限：會安裝程式、匯入自簽憑證、必要時安裝 WebView2 執行環境）。
4. 安裝完成後，程式本體不會再被 Windows 擋。

> 內含 .NET 執行環境（self-contained），對方不必另裝 .NET。
