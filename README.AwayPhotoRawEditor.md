## v1.0.3 更新內容

- 風格檔「備份全部／還原全部」（重灌電腦可帶回全部風格檔設定）

## 安裝說明

1. 下載並執行 `AwayPhotoRawEditor-Setup-v1.0.3.exe`。
2. 若跳出「Windows 已保護你的電腦」→ 點 **其他資訊 → 仍要執行**。
3. 安裝為**每使用者**，不需系統管理員權限（不會出現 UAC）。
4. 內含 .NET 執行環境（self-contained），不必另裝 .NET。
